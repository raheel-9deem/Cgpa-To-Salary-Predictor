# 🎓 CGPA to Salary Predictor

## 📌 Overview
This repository contains a Machine Learning project designed to predict a student's expected salary package based entirely on their academic performance (CGPA). The model was trained and evaluated to help understand the linear relationship between grades and initial career compensation.

## 🚀 Tech Stack
* **Language:** Python
* **Environment:** Google Colab
* **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib

## 🧠 Model Details
* **Algorithm Used:** Simple Linear Regression
* **Model Accuracy / R² Score:** 78.07%
* **Feature (X):** Student CGPA
* **Target (Y):** Salary Package

## ⚙️ Key Concepts Applied
* Data Preprocessing and handling missing values.
* Train-Test Split with a fixed `random_state` for reproducible results.
* Evaluation of the bias-variance tradeoff to ensure the model doesn't overfit.
